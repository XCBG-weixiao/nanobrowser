# 白名单自动审批改造方案

确认日期：2026-11-02。状态：用户已确认，实施前提交。

同时改造 Nanobrowser 和 dbgpt，采用内网服务执行、浏览器插件对话与桌面通知的结构。

1. **访问范围**：Agent 只能读取和操作配置的平台网址及其子路径。URL 使用精确协议、主机、端口和路径边界匹配；覆盖页面读取、截图、操作、导航、标签页及 iframe，不影响平台正常请求自己的 API。
2. **持续监测**：dbgpt 内网服务每 30 秒检查一次。启用时处理全部已有待审批申请，之后持续处理新增申请。任务持久化，服务重启后恢复。
3. **自动审批**：通过专用业务能力执行同意操作。稳定申请 ID、状态版本、事务和幂等记录保证可追踪；不覆盖人工拒绝或撤销，不重复审批。
4. **桌面通知**：审批成功后由 Nanobrowser 展示浏览器桌面通知。Chrome 退出期间服务端保存待发通知，客户端恢复后补发。通知失败不重新执行审批。
5. **控制入口**：插件提供启用、暂停和查看结果功能，并接入对话工具。模型、数据和状态都留在内网；固定审批流程不调用模型。

采用单执行器，借鉴 SuperAgent 的事件触发、任务持久化和恢复设计。接口异常时报告明确错误，不切换为猜测页面按钮等替代机制。
